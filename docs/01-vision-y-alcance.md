# Vision y alcance

## Nombre del sistema

Vitalis

## Descripcion general

Vitalis es un sistema web para la gestion integral de un consultorio medico virtual. Permite centralizar la atencion administrativa y clinica mediante la gestion de pacientes, agenda de turnos, historia clinica electronica, prescripciones, facturacion, sala de espera virtual y reportes de gestion.

## Problema

Muchos consultorios medicos gestionan su informacion de forma fragmentada mediante planillas, mensajes, papel o sistemas aislados. Esto dificulta el seguimiento clinico del paciente, la organizacion de turnos, la administracion de cobros, el control de prestaciones y la obtencion de indicadores para tomar decisiones.

## Objetivo general

Desarrollar un sistema web de gestion para un consultorio medico virtual que permita administrar los procesos clinicos, administrativos y operativos principales, mejorando la trazabilidad de la informacion, la organizacion de la atencion y el acceso a reportes.

## Objetivos especificos

- Gestionar usuarios con distintos roles y permisos.
- Administrar pacientes, datos personales, cobertura medica y antecedentes.
- Registrar consultas medicas en una historia clinica electronica.
- Gestionar agenda, turnos, cancelaciones y reprogramaciones.
- Administrar una sala de espera virtual para ordenar la atencion.
- Emitir prescripciones y recetas asociadas a consultas.
- Registrar prestaciones, pagos, facturacion y liquidaciones.
- Generar reportes estadisticos para la toma de decisiones.
- Mantener parametros administrativos como especialidades, profesionales, obras sociales y prestaciones.

## Alcance incluido

- Aplicacion web para personal administrativo, profesionales medicos y pacientes.
- Gestion integral del flujo de atencion: turno, espera, consulta, receta y cobro.
- Autenticacion con roles.
- Auditoria basica de operaciones importantes.
- Reportes operativos y administrativos.

## Fuera de alcance inicial

- Integracion real con sistemas nacionales de receta electronica.
- Firma digital legalmente valida.
- Pasarela de pago real.
- Videollamada integrada.
- Aplicacion movil nativa.
- Interoperabilidad HL7/FHIR completa.

Estas funcionalidades pueden mencionarse como futuras mejoras.
